# History

What each phase built, oldest first. Each phase had one branch named `phase-N-topic`, stacked on the previous one. The household's first week with the app was 19 October 2026.

The original plan: 0 scaffold, 1 schema and domain logic, 2 recipe import, 3 auth and UI, 4 recurring items, leftovers, at-home step, history, 5 recommendations, 6 deployment, PWA, export. Later phases were named by what the family needed. The suggestions were planned as phase 5 and came forward into phase 3b: the household wants planning to start from them.
